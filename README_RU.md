# Happwner PC

Настольный локальный сервер подписок для Windows и Linux. Программа получает подписки Happ, расшифровывает их и раздаёт VPN-клиентам на этом компьютере или другим устройствам в домашней сети.

Проект является некоммерческим форком Android-приложения [Happwner](https://github.com/Omegaplexx/Happwner). Android, Xposed и LSPatch-функции удалены — в форке осталось переносимое ядро расшифровки, конвертации и «Мост» подписок.

## Возможности

- постоянные адреса вида `http://127.0.0.1:8166/sub/<UUID>`;
- LAN-режим для раздачи через `http://192.168.x.x:8166`;
- поддержка HTTP(S), `happ://add`, `happ://crypt`–`crypt5`, `v2raytun://crypt`, `v2raytun://import`, `incy://add` и `incy://import`;
- передача `x-hwid` и выбранного `User-Agent` провайдеру;
- расшифровка ответов Happ с заголовком `Encrypt-Tag`;
- дополнительные преобразования Base64, JSON → URI и Xray → sing-box;
- управление подписками из окна, работа в системном трее и автозапуск;
- совместимость со старыми ссылками `/url=...&hwid=...&ua=...` на локальном компьютере.

## Запуск из исходников

Требуется JDK 21. Java не требуется конечному пользователю после создания нативного дистрибутива.

```bash
./gradlew :desktop:run
```

Сборка переносимого приложения:

```bash
./gradlew :desktop:createDistributable
```

Создание установщика текущей ОС:

```bash
./gradlew :desktop:packageDistributionForCurrentOS
```

Результаты находятся в `desktop/build/compose/binaries`.

## Использование

1. Добавьте подписку, задайте название, исходную ссылку, HWID и User-Agent.
2. Оставьте локальный режим для клиентов на этом ПК либо включите «Домашняя сеть (LAN)».
3. Скопируйте адрес подписки и вставьте его в NekoBox, Hiddify, v2rayNG или другой совместимый клиент.
4. Если телефон не открывает `/health`, разрешите входящие TCP-подключения к выбранному порту в брандмауэре ОС.

Сервер по умолчанию слушает только `127.0.0.1:8166`. В LAN-режиме он слушает все IPv4-интерфейсы, а интерфейс показывает найденные частные адреса.

## Безопасность

По выбранной модели домашний режим работает без авторизации. Любой участник локальной сети, получивший адрес `/sub/<UUID>`, сможет скачать соответствующую конфигурацию. Используйте LAN-режим только в доверенной домашней сети и не публикуйте порт в Интернет.

Старые ссылки с произвольным исходным URL принимаются только с loopback-адреса. Это не позволяет устройствам в LAN использовать ПК как произвольный HTTP-прокси.

Настройки хранятся в `%APPDATA%/HappwnerPC` на Windows и `${XDG_CONFIG_HOME:-~/.config}/happwner-pc` на Linux.

## Разработка и тесты

```bash
./gradlew test
```

Проект разделён на два модуля:

- `core` — форматы ссылок, криптография и конвертеры;
- `desktop` — Compose Desktop, сервер, хранилище, трей и автозапуск.

## Авторы и условия
