# Happwner PC 0.1.5 Preview

[English version](RELEASE_0.1.5.md)

Это первый предварительный выпуск Happwner PC — настольного Bridge-сервера подписок для Linux, который расшифровывает и преобразует подписки, а затем раздаёт их локально или в доверенной домашней сети.

## Что готово

- постоянные локальные адреса подписок;
- необязательный доступ для всей домашней сети с выбором интерфейса и QR-кодами;
- обработка источников Happ, v2RayTun, INCY, HTTP и HTTPS;
- расшифровка ответов Happ и преобразования Base64/JSON/Xray;
- проверка подписки с подсчётом профилей и протоколов;
- тёмный настольный интерфейс, системный трей, автозапуск и постоянное хранение настроек;
- переносимый Linux-архив и пакеты для Arch Linux, Debian/Ubuntu и Fedora/openSUSE.

## Установка

Выберите пакет для своего дистрибутива:

| Дистрибутив | Файл |
| --- | --- |
| Arch Linux | `happwner-pc-bin-0.1.5-3-x86_64.pkg.tar.zst` |
| Debian/Ubuntu | `happwner-pc_0.1.5_amd64.deb` |
| Fedora/openSUSE | `happwner-pc-0.1.5-1.x86_64.rpm` |
| Другой Linux x86_64 | `happwner-pc-0.1.5-linux-x86_64.tar.gz` |

### Arch Linux

```bash
sudo pacman -U happwner-pc-bin-0.1.5-3-x86_64.pkg.tar.zst
```

### Debian/Ubuntu

```bash
sudo apt install ./happwner-pc_0.1.5_amd64.deb
```

### Fedora

```bash
sudo dnf install ./happwner-pc-0.1.5-1.x86_64.rpm
```

### openSUSE

```bash
sudo zypper install ./happwner-pc-0.1.5-1.x86_64.rpm
```

### Переносимый архив

```bash
tar -xzf happwner-pc-0.1.5-linux-x86_64.tar.gz
./Happwner\ PC/bin/Happwner\ PC
```

Все пакеты содержат среду выполнения Java. Проверьте загруженные файлы по приложенному `SHA256SUMS`:

```bash
sha256sum -c SHA256SUMS
```

## Перед сообщением о проблеме

Укажите:

- дистрибутив Linux и окружение рабочего стола;
- название и версию VPN-клиента;
- режим сервера: локальный или LAN;
- показанное сообщение об ошибке или HTTP-статус;
- шаги для воспроизведения проблемы.

Не публикуйте исходные адреса подписок, HWID, расшифрованные профили и другие учётные данные.

## Ограничения Preview

Ядро подписок и HTTP-сервер покрыты автоматическими тестами, но выпуск ещё не проверен со всеми целевыми VPN-клиентами и окружениями рабочего стола. Пакеты Windows запланированы на следующий предварительный выпуск.

Подробности реализации и отличия от Android Happwner 1.3 описаны в [аудите совместимости ядра](CORE_AUDIT_RU.md).
