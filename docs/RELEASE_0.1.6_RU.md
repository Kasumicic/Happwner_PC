# Happwner PC 0.1.6

[English version](RELEASE_0.1.6.md)

Happwner PC 0.1.6 — первый стабильный публичный настольный релиз с автоматическими пакетами Linux и Windows, безопасной диагностикой, сведениями о трафике подписки и надёжным преобразованием профилей.

## Что нового

- MSI-установщик и переносимый ZIP для Windows, собираемые GitHub Actions;
- журнал диагностики в памяти и безопасный отчёт без секретов подписки;
- прямое копирование полного списка загруженных, расшифрованных и преобразованных профилей;
- отображение трафика, лимита, остатка и срока подписки из `Subscription-Userinfo`;
- контакты авторов и проектов в настройках;
- заметки о совместимости Android-клиентов, включая временный прямой режим для Incy;
- преобразование всех outbound-профилей Xray JSON и исправленные IPv6-ссылки;
- дополнительные тесты лимита ответа, параллельных клиентов и отключённых подписок.

## Загрузка

Выберите подходящий файл среди материалов GitHub Release:

| Система | Файл |
| --- | --- |
| Установщик Windows x64 | `Happwner PC-0.1.6.msi` |
| Переносимая версия Windows x64 | `happwner-pc-0.1.6-windows-x64.zip` |
| Arch Linux x86_64 | `happwner-pc-bin-0.1.6-3-x86_64.pkg.tar.zst` |
| Debian/Ubuntu x86_64 | `happwner-pc_0.1.6_amd64.deb` |
| Fedora/openSUSE x86_64 | `happwner-pc-0.1.6-1.x86_64.rpm` |
| Другой Linux x86_64 | `happwner-pc-0.1.6-linux-x86_64.tar.gz` |

Точные имена нативных пакетов могут немного отличаться. Все пакеты включают среду Java. Загруженные файлы можно проверить с помощью приложенного `SHA256SUMS`.

## Заметки о тестировании

Автоматические тесты покрывают ядро подписок, HTTP-сервер, конвертеры, совместимость шифрования, лимиты ответа и параллельных клиентов. Ручная проверка Android подтвердила LAN-ссылки в Exclave, Husi, Happ и NekoBox. Incy блокирует незашифрованный LAN HTTP; временный прямой режим и его ограничения описаны в [таблице совместимости клиентов](CLIENT_COMPATIBILITY_RU.md).

MSI-установщик и переносимый ZIP проверены вручную на реальной системе Windows. Установка, запуск, системный трей, обработка подписок и локальный сервер работают исправно. Не открывайте LAN-сервер напрямую в публичный интернет и не публикуйте в отчётах исходные URL, HWID, скопированные профили и другие секреты.
